# Fairway Golf

A mobile-friendly golf web app with 9- and 18-hole scorecards, round statistics, club carry distances, and seven practice games.

## Use
Open index.html in a browser or enable GitHub Pages from main / (root).

## Data
Scores, in-progress rounds, and clubs are saved in this browser on this device. Use the clubhouse backup export to keep a copy. This version does not sync data across devices.

## Validation
Round creation, automatic save and resume, a completed 9-hole scorecard, practice scoring and undo, two-player practice, and saved club distance matching were tested in browser.
