# Fairway Golf

Mobile-friendly golf scorecards, round stats, club carry distances, and seven practice games.

## Hosting
Enable GitHub Pages from the main branch, / (root). No build or paid service required.

## Your data
Scores, rounds, and clubs save in this browser on this device. Export a backup from the clubhouse. This version does not sync between devices.

## Tested
Practice scoring, undo, pass-and-play, saved progress, round resume, 9-hole totals, and club-distance matching.
